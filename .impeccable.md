## Design Context

> Updated in Stage 3 of the 2026 revamp. This replaces the earlier "dark techy"
> brief (Bricolage Grotesque, purple/cyan glow, network canvas), which the club
> moved away from. Tokens and components live in `src/index.css` under
> `.theme-pixel`; this file explains the intent behind them.

### Users
University of Houston students, mostly 18–24, many on phones, from CS majors to
business students curious about cloud. A first-time student needs to see the
next event and how to join within one scroll; a returning member wants their
learning progress and what's next. They respond to authenticity over polish.

### Direction: "pixel night sky, modern underneath"
Retro, game-like, colourful, but never at the cost of reading or using the
site. Pixel art carries the personality (sky, mascot, component shapes,
headlines); layout, body text, spacing and accessibility stay modern.

### Palette (named, every text pair ≥ 6:1)
- Orbit `#2B2072`: page background (bright night violet)
- Hull `#3A2D8F`: raised panels; Hull dark `#2A1F73` wells and footer
- Starlight `#F6F3FF`: text; Dust `#D4CCF8`: secondary text; Link `#E2CFFF`
- Chip `#AD5CFF`: the logo's violet. Mascot, window title bars, avatar frames
- Beacon `#FFD34D`: the one action colour (join, RSVP, next step) and focus

### Type
- **Jersey 10** (SIL OFL, Google Fonts): h1/h2, button labels, title bars,
  date tiles, the level readout. Set large (it runs small).
- **Figtree**: everything people read at length, and h3.
- The one h1 per page is Beacon yellow with a two-step pixel extrusion.

### Components (see `.theme-pixel` in `src/index.css`)
- Notched pixel corners via four un-blurred box-shadows (no clip-path, so
  focus outlines are never clipped), two-tone bevels.
- `px-button` (one primary action per view, presses in), `px-link`,
  `px-panel`, `px-window` + `px-titlebar` (only for the most important panel
  on a page), `px-chip` (real labels only), `px-option`, `px-input`,
  `px-check`, `px-xp`, `px-date`, `px-avatar`.
- `PixelIcon`: original 9×9 icon set. Brand logos stay official.
- `Mascot`: original pixel astronaut (chip-violet visor, chip badge). Used for
  the hero, empty and error states, and the 404. Decorative.
- Hero art: `src/assets/pixel-sky-*.png`, generated by
  `scripts/pixel_sky.py`; clouds and stars are kept out from behind text.

### Principles
1. **Next event and joining first.** Every design choice serves the student
   journeys; decoration never pushes them below the fold.
2. **One loud thing per view.** The extruded headline and the Beacon button
   are loud; everything else is quiet.
3. **Pixel shapes, modern behaviour.** Real buttons, checkboxes and links
   underneath; visible Beacon focus; 44px targets; WCAG AA contrast.
4. **Motion only with meaning.** The mascot's float is the only ambient
   motion and stops under prefers-reduced-motion; buttons press in on click.
5. **No template tells.** No ALL-CAPS eyebrows, no accented single headline
   word, no 01/02/03 unless it's a real sequence (the learning path is), no
   arrow on every link, no invented stats or testimonials.
